# Encapsulation

## Definition:

1. Encapsulation binds data and methods in a class.
2. Like a capsule, it combines and binds them together.

## Function of Encapsulation:

1. Provides a secure layer.
2. Hides internal implementation of code and data in a class.
3. Exposes only necessary information to the external world.

## Additional Points:

1. As we are hiding data from outer classes or the world, Encapsulation is also known as **Data Hiding**.
2. The goal is to implement classes in a way that prevents unauthorized access to or modification of the original contents of a class by its instances (or objects).
3. The algorithms of one class need not be known to another class, though the two classes can still communicate.

# Access Modifiers

1. Access modifiers are used to define access to the data and methods of a class.

## Public

1. Members declared as `public` are accessible from any part of the program.
2. They can be accessed by objects of the class and external code.

## Private

1. Members declared as `private` are accessible only within the same class.
2. They are not accessible from outside the class, including derived classes.

## Protected

1. Members declared as `protected` are accessible within the same class and by derived classes.
2. They are not directly accessible from external code.

Design Strategy
Abstraction divides code into two parts:
Interface
Implementation
The interface should remain separate from the implementation.
If the internal implementation changes, the interface can still remain the same.
Programs using the interface remain unaffected by implementation changes.
Only recompilation with the latest implementation may be required.
Abstraction helps in:
Modular programming
Better maintainability
Flexible and reusable code design
